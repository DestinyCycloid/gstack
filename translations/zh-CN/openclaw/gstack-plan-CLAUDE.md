# gstack-plan: 完整评审流程

当用户想要规划 Claude Code 项目时由编排器注入。
追加到现有的 CLAUDE.md。

## 规划流程
1. 阅读 CLAUDE.md 并理解项目上下文。
2. 运行 /office-hours 生成设计文档(问题陈述、前提条件、备选方案)。
3. 运行 /autoplan 评审设计(CEO + 工程 + 设计 + DX 评审 + codex 对抗性评审)。
4. 将最终评审后的计划保存到编排器稍后可以引用的文件中。
   写入到:当前仓库中的 plans/<project-slug>-plan-<date>.md。
   包含设计文档、所有评审决策和实施顺序。
5. 向编排器报告:
   - 计划文件路径
   - 关于设计内容和关键决策的一段话摘要
   - 已接受的范围扩展列表(如有)
   - 推荐的下一步(通常是:使用 gstack-full 启动新会话来实施)

不要实施任何内容。这仅用于规划。
编排器将把计划链接持久化到其自己的内存/知识存储中。
