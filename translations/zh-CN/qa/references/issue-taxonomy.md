# QA 问题分类

## 严重程度级别

| 严重程度 | 定义 | 示例 |
|----------|------------|----------|
| **critical** | 阻塞核心工作流、导致数据丢失或应用崩溃 | 表单提交导致错误页面、结账流程中断、数据未经确认被删除 |
| **high** | 主要功能损坏或无法使用,无解决方法 | 搜索返回错误结果、文件上传静默失败、认证重定向循环 |
| **medium** | 功能可用但存在明显问题,有解决方法 | 页面加载缓慢(>5秒)、表单验证缺失但提交仍可用、仅移动端布局损坏 |
| **low** | 轻微的外观或细节问题 | 页脚拼写错误、1像素对齐问题、悬停状态不一致 |

## 类别

### 1. 视觉/UI
- 布局损坏(元素重叠、文本被裁剪、水平滚动条)
- 图片损坏或丢失
- 错误的 z-index(元素显示在其他元素后面)
- 字体/颜色不一致
- 动画故障(卡顿、过渡不完整)
- 对齐问题(偏离网格、间距不均)
- 深色模式/主题问题

### 2. 功能性
- 链接损坏(404、错误目标)
- 按钮失效(点击无响应)
- 表单验证(缺失、错误、被绕过)
- 错误的重定向
- 状态未持久化(刷新后数据丢失、返回按钮)
- 竞态条件(重复提交、过期数据)
- 搜索返回错误或无结果

### 3. UX
- 导航混乱(无面包屑、死胡同)
- 缺少加载指示器(用户不知道正在进行操作)
- 交互缓慢(>500毫秒且无反馈)
- 错误消息不清晰("出错了"但无详细信息)
- 破坏性操作前无确认
- 页面间交互模式不一致
- 死胡同(无返回路径、无下一步操作)

### 4. 内容
- 拼写和语法错误
- 过时或不正确的文本
- 遗留的占位符/lorem ipsum 文本
- 文本截断(被截断且无省略号或"更多")
- 按钮或表单字段标签错误
- 空状态缺失或无用

### 5. 性能
- 页面加载缓慢(>3秒)
- 滚动卡顿(掉帧)
- 布局偏移(加载后内容跳动)
- 过多的网络请求(单页面>50个)
- 大型未优化图片
- 阻塞的 JavaScript(加载期间页面无响应)

### 6. 控制台/错误
- JavaScript 异常(未捕获的错误)
- 网络请求失败(4xx、5xx)
- 弃用警告(即将损坏)
- CORS 错误
- 混合内容警告(HTTPS 上的 HTTP 资源)
- CSP 违规

### 7. 无障碍性
- 图片缺少 alt 文本
- 表单输入未标记
- 键盘导航损坏(无法 tab 到元素)
- 焦点陷阱(无法退出模态框或下拉菜单)
- ARIA 属性缺失或错误
- 颜色对比度不足
- 屏幕阅读器无法访问内容

## 每页探索检查清单

在 QA 会话期间访问的每个页面:

1. **视觉扫描** — 截取带注释的屏幕截图(`snapshot -i -a -o`)。查找布局问题、损坏的图片、对齐问题。
2. **交互元素** — 点击每个按钮、链接和控件。每个是否按预期工作?
3. **表单** — 填写并提交。测试空提交、无效数据、边界情况(长文本、特殊字符)。
4. **导航** — 检查所有进出路径。面包屑、返回按钮、深层链接、移动菜单。
5. **状态** — 检查空状态、加载状态、错误状态、满/溢出状态。
6. **控制台** — 交互后运行 `console --errors`。是否有新的 JS 错误或失败的请求?
7. **响应式** — 如相关,检查移动端和平板视口。
8. **认证边界** — 登出时会发生什么?不同的用户角色?
